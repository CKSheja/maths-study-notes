# Maths study notes

I am now revisiting mathematics alongside my software engineering studies.

I recently started Stanford's Probability for AI course to understand more of the mathematics behind AI. This repository is where I am working through other foundations, starting with precalculus and linear algebra.

## Study approach

For each topic, I work through a small example, show the calculations and use Python to check or explore the result.

These are independent study notes, not coursework submitted for university credit. The repository will grow as I work through more topics.
